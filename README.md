# GAMEpiada 🏆 · Esports Arena (v4.7)

Статический сайт турнира **GAMEpiada, сезон I**: 17 дисциплин, 8 бойцов, круговые турниры «каждый с каждым» и заезды по официальному регламенту, дуо-синергия и статистика из ответов Google-формы.

> **Даты не выдумываем.** Календарных дней у турнира пока нет — на сайте честное «даты уточняются», а вместо расписания по дням стоит **очередь слотов**: порядок, примерное время MSK и длительность.
>
> **Таблица только читается.** Сайт ничего не пишет в Google Sheets — данные забираются публичным `gviz`-эндпоинтом, а в репозитории лежит снимок ответов на случай офлайна.

## Что внутри

| Файл | Роль |
| --- | --- |
| `index.html` | разметка: hero, секции, блок соревнований (круговая/заезд), модалки, палитра, док |
| `styles.css` | дизайн-система v4: киберспортивные токены, тёмная/светлая тема, подиум, адаптив |
| `data.js` | снимок турнира: событие, 17 дисциплин с форматами из регламента, состав, волны |
| `app.js` | рендер, фильтры, круговые таблицы, подиумы, дуо-синергия, статистика, JSONP-синк |
| `sw.js` | офлайн-режим (PWA), network-first для навигации |
| `assets/og.jpg` | OG-картинка 1200×630 для соцсетей |
| `assets/games/*.jpg` | арт-фоны карточек турниров: 17 файлов 640×360, ленивая загрузка (источники — в `assets/games/CREDITS.md`) |
| `test-site.js` | jsdom-регрессия: 163 проверки рендера, интерактива и анти-регрессий |

Ноль зависимостей в рантайме: без фреймворков, сборщиков и API-ключей. Node нужен только для тестов.

## Форматы соревнований

- **Круговая** (`comp.kind = 'bracket'`) — каждый с каждым: Dota 2 и CS 2 (по 1×1 и 2×2), Clash Royale, Rocket League, Geoguessr, Fortnite, Mortal Kombat 11, Minecraft PvP, шахматы, Brawl Stars — 12 дисциплин. N участников → N−1 раундов по круговому методу (при нечётном составе один боец отдыхает каждый раунд), (N−1)·N/2 матчей. Победа = 1 очко, место в таблице = итоговое место турнира. Серии BO1/BO3 и правила — из регламента.
- **Заезд** (`comp.kind = 'board'`) — общий зачёт с местами 1/2/3: Double Dealers, Geometry Dash, Minecraft Duo, Fall Guys, Trackmania (5 дисциплин). Ветка тут не нужна, поэтому показывается подиум.
- Очки: 3 / 2 / 1 за места; в командах 2×2 делятся — 1,5 / 1 / 0,5.

## Фичи

- **Живой состав из Google Таблицы** — JSONP-запрос к `gviz/tq`, мягкий фолбэк на снимок, статус синка и кнопка «Повторить».
- **Круговая сетка как на Challonge**: раунды строками («Раунд 1…N» и по 4 матча в ряд), в карточке матча — номер, сид и ник бойца, счёт-чип 1:0 (клик по бойцу — победа), оранжевая подсветка победителя; таблица `Место / Участник / 1. Матчи В-П-Н / 2. Тай-брейк / 3. Победы / Ничьи / 4. Очки`, мини-таблица личных встреч как тай-брейк, автопрогноз, пересборка раундов и сброс, баннер чемпиона после последнего матча.
- **Правка состава «кто в какой сетке»** — панель «Кто играет в этой сетке» прямо в блоке турниров: чип на каждого бойца, клик добавляет или убирает из текущей сетки, тут же счётчик и «сбросить». Дополнительно кнопка «👥 Состав» (поиск по бойцам), режим «✎ Правка состава» в матрице дисциплин и кнопки «Изменить состав» / «Изменить арены» в модалках: клик добавляет или убирает бойца, круги, таблица и матрица пересобираются сразу. Правки хранятся отдельным слоем в `localStorage` (`gamepiada-roster-v1`) поверх ответов формы, переживают live-синк Google Таблицы, сбрасываются кнопкой «Сбросить к форме» и переносятся на другое устройство ссылкой `?r=…#bracket`.
- **Подиум 1–3** для заездов: металлические ступени 2–1–3, медальные бейджи, сияние у чемпиона, селекты мест, автоподбор по силе состава, конфетти при сборе подиума, очки в живом зачёте.
- **Бриф регламента** под каждым турниром: формат, серия/метрика, условие победы, очки и чипы «уточнить до старта».
- **Дуо-лаб**: синергия по общим аренам, взаимным пожеланиям и связям, карточки лучших пар.
- **Статистика**: топ арен, лидерборд универсальности, донат соло/дуо, факты.
- **Очередь слотов**: 5 волн + окно доигрывания, длительности, честный `TBD` вместо обратного отсчёта.
- **Пожелания** из формы с лайками (localStorage).
- **Командная палитра** `⌘K` / `Ctrl+K`: дисциплины, бойцы и быстрые действия.
- **Арт-фоны турниров**: у каждой дисциплины свой кадр (key art / геймплей) под градиентом, в карточке, шапке модалки и под круговой/подиумом.
- **Оформление**: тёмная киберспортивная палитра с неоном, светлая тема, `prefers-reduced-motion`; без кастомного курсора, canvas-звёзд, 3D-тилта и полноэкранных `backdrop-filter` — чтобы не лагало.
- **Свежая версия без «залипшего» кеша**: ссылки на `styles.css`/`app.js` версионированы (`?v=4.7.0`), service worker качает JS/CSS сетью в приоритете, в подвале видна версия и кнопка «обновить» — она чистит Cache Storage и снимает SW.
- **PWA**: манифест, иконки, service worker, офлайн-кэш.

## Локальный запуск

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
npm install && npm test   # jsdom-регрессия
```

Сервер нужен, чтобы работали `fetch`/JSONP и service worker (с `file://` часть эффектов отключится).
