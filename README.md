# GAMEpiada 🏆 — турнирный центр v2.5 «Celestial+»

Самодостаточный статический сайт турнирного центра GAMEpiada: карточки 17 дисциплин, редактируемое расписание, ростер игроков и команд, сетки на выбывание / круговые, фиксация матчей, общий зачёт и календарь.

**Ноль зависимостей**: не нужны Node.js, npm, внешние библиотеки или API-ключи — один файл `index.html`.

## Что нового в v2 (полностью переработано)

**Дизайн уровня продукта**
- Новая дизайн-система: стеклянные панели, аврора-фон со звёздами, золотые акценты, медали с металлическими градиентами.
- Микроанимации: появление страниц, счётчики, прогресс-кольца, hover-эффекты, конфетти при победе.
- Адаптив от телефона до широкого монитора, поддержка `prefers-reduced-motion`, стили печати.

**Продуктовые фичи**
- ⌘ **Командная палитра** `Ctrl+K`: переход к любой дисциплине/участнику, быстрые действия.
- ↩️ **Undo / Redo** (`Ctrl+Z` / `Ctrl+Shift+Z`) — любую ошибку можно отменить.
- Клик по участнику матча сразу назначает победителя; счёт вводится отдельно и сам определяет победителя.
- SVG-коннекторы турнирной сетки, авто-жеребьёвка, баннер чемпиана, автозаполнение пьедестала из сетки.
- Таблица кругового этапа (победы/поражения/очки) считается автоматически.
- Отдельная страница **«Общий зачёт»** с пьедесталом, диаграммами очков и экспортом CSV.
- Календарь: статусные бейджи (сегодня / скоро / доигрывание / завершена), экспорт расписания в **ICS** (Google/Apple Calendar), включая отдельные события.
- Обратный отсчёт до старта турнира, живые метрики, статусы дисциплин.
- Стильные диалоги подтверждения вместо системных `confirm()`, стек уведомлений с кнопкой «Отменить».
- Демо-ростер в один клик (12 участников) для проверки сеток.

**Исправления логики**
- 🐛 Исправлен унаследованный баг сетки на выбывание: раньше участник с «BYE» автоматически проходил **и следующие раунды**, пока соперник не сыграл свой матч, — сетка «схлопывалась» и финал решался сам. Теперь автопроход работает только для реальных пустых слотов первого раунда.

**v2.5 — второй раунд улучшений**
- 🌗 **Светлая и тёмная тема** с переключателем (запоминается в браузере).
- 👤 **Профили игроков**: очки, победы, win-rate, личные встречи (head-to-head) и история матчей — кликни по участнику в любой таблице.
- 🥉 **Матч за 3-е место** в сетке на выбывание + автозаполнение bronze-финала и топ-3 кругового этапа.
- 📜 **Хроника турнира**: лента событий на главной (победы, пьедесталы, изменения ростера).
- 🔗 **Ссылка-снапшот**: одна кнопка упаковывает весь турнир (сжатие deflate) в URL; получатель открывает его в безопасном **режиме просмотра** и может сделать себе локальную копию.
- 🕘 **История изменений**: автоматические локальные снапшоты после каждого действия (до 25) с восстановлением в один клик.
- 🖨 Печать сетки, кнопка «Сегодня» в календаре, сортировка таблицы зачёта кликом по заголовкам, Enter в поиске, PWA-офлайн (service worker).

**Данные и надёжность**
- Полная совместимость с данными v1: старый `localStorage` и JSON-бэкапы загружаются без потерь (миграция до версии 2).
- Автосохранение с индикатором времени, валидация импорта, экранирование пользовательского ввода (XSS-safe).

## Запуск локально

Открой `index.html` в браузере или запусти локальный сервер:

```bash
python -m http.server 8080
```

## Публикация на GitHub Pages

1. Создай GitHub-репозиторий (например, `gamepiada`).
2. Загрузи в корень репозитория `index.html`, `favicon.svg`, `site.webmanifest`, `.nojekyll` и папку `assets/`.
3. Открой **Settings → Pages**.
4. Выбери **Deploy from a branch → main → /(root)** и нажми **Save**.
5. После сборки GitHub покажет адрес вида `https://<username>.github.io/gamepiada/`.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+K` | Командная палитра (разделы, дисциплины, участники, действия) |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Отменить / повторить |
| `/` | Фокус на поиск |
| `Esc` | Закрыть окно |

## Функции

- Добавление, изменение и удаление дисциплин, игроков и команд.
- Индивидуальные настройки дисциплин: дата, слот, цвет, правила, формат сетки, BO1/BO3/BO5.
- Жеребьёвка, сетка single elimination с автоматическими BYE и круговой формат.
- Сохранение счёта и победителей матчей, автоматический перенос победителей по сетке.
- Ручное назначение пьедестала и очков 3–2–1; очки команд распределяются между участниками состава.
- Общий рейтинг с диаграммами, экспорт CSV, экспорт календаря ICS, экспорт/импорт полной резервной копии JSON.
- Автосохранение в `localStorage`, undo/redo, командная палитра.

## Важное ограничение статического хостинга

GitHub Pages публикует статические файлы. Данные турнира сохраняются в браузере на том устройстве, где администратор вносит изменения; они **не синхронизируются автоматически между разными пользователями**. Экспортируй JSON и распространяй новую версию резервной копии либо подключи отдельную БД/API, если нужна общая онлайн-таблица и права доступа.
