# GAMEpiada 🏆 · Celestial Arena

Статический сайт турнира **GAMEpiada, сезон I** (27 октября — 1 ноября 2026): 17 дисциплин, 8 бойцов, интерактивные сетки, дуо-синергия и статистика, собранная из ответов Google-формы.

> **Таблица только читается.** Сайт ничего не пишет в Google Sheets — данные забираются публичным `gviz`-эндпоинтом, а в репозитории лежит снимок ответов на случай офлайна.

## Что внутри

| Файл | Роль |
| --- | --- |
| `index.html` | вся разметка: hero, 8 секций, модалки, палитра, док |
| `styles.css` | дизайн-система v3: токены, стекло, 3D-тилт, светлая/тёмная тема, адаптив |
| `data.js` | снимок турнира: событие, 17 дисциплин, 8 ответов формы, расписание |
| `app.js` | рендер, фильтры, сетки, дуо-синергия, статистика, JSONP-синк, эффекты |
| `sw.js` | офлайн-режим (PWA), network-first для навигации |
| `assets/og.jpg` | OG-картинка 1200×630 для соцсетей |
| `test-site.js` | jsdom-регрессия: 50+ проверок рендера и интерактива |

Ноль зависимостей в рантайме: без фреймворков, сборщиков и API-ключей. Node нужен только для тестов.

## Фичи

- **Живой состав из Google Таблицы** — JSONP-запрос к `gviz/tq`, мягкий фолбэк на снимок, статус синка и кнопка «Повторить».
- **Интерактивные сетки** single elimination для каждой дисциплины: клик по бойцу, BYE-слоты, SVG-коннекторы, автопрогноз, шаффл и сброс, баннер чемпиона.
- **Дуо-лаб**: синергия по общим аренам, взаимным пожеланиям и связям, кольцо-прогресс и карточки лучших пар.
- **Статистика**: топ арен, лидерборд универсальности, донат соло/дуо, занимательные факты.
- **Расписание** по дням с подсветкой «сегодня», обратным отсчётом и экспортом в `.ics`.
- **Пожелания** из формы с лайками (localStorage).
- **Командная палитра** `⌘K` / `Ctrl+K`: дисциплины, бойцы и быстрые действия.
- **Оформление**: аврора, звёздное поле, сетка-перспектива, 3D-тилт карточек, курсор-хало, конфетти, звук, светлая/тёмная тема, `prefers-reduced-motion`.
- **PWA**: манифест, иконки, service worker, офлайн-кэш.

## Локальный запуск

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Сервер нужен, чтобы работали `fetch`/JSONP и service worker (с `file://` часть эффектов отключится).

## Тесты

```bash
npm install          # поставит только jsdom
npm test
```

Харнесс поднимает `index.html` в jsdom, подменяет canvas/IO/RAF, эмулирует ответ Google Таблицы и проверяет 50+ сценариев: фильтры, модалки, сетку, дуо, палитру, live-синк и отсутствие JS-ошибок.
